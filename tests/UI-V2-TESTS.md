# v2.0 Windows arayüz kontrol listesi

Henüz Windows üzerinde çalıştırılmadı.

- [ ] Önceki veritabanı ile mevcut kullanıcı giriş yapabiliyor.
- [ ] Açılış ekranı ilerleme animasyonundan giriş ekranına geçiyor; başlık ve alt başlık sırayla beliriyor.
- [ ] Enter ile giriş, yanlış şifre uyarısı, ilk kurulum, pencereyi açılışta kapatma çalışıyor.
- [ ] Hover, klavye odağı, tıklama, tablo satırı geçişleri takılmadan çalışıyor.
- [ ] Tüm formlarda pencereyi minimum boyuta küçültme ve büyütme: kesilen metin veya çakışan kontrol yok.
- [ ] Windows %100 ve %125 ekran ölçeğinde görünüm kontrolü.
- [ ] Ürün, müşteri, personel, tedarikçi ve kategori ekleme/güncelleme/silme.
- [ ] Satış adedi düzenleme, satış yapma, satış iptali, azalan stok ve arama.
- [ ] Personel rolü yönetici menüsünü göremiyor.
- [ ] Windows animasyonları kapalıyken giriş gecikmeden açılıyor.
